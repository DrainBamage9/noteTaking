# New Functions from Old Functions 

## Transformations

Given $y=f(x)$

### Vertical shift
$f(x)+c:$ up c

$f(x)−c:$ down c
### Horizontal shift
$f(x−c):$ right c

$f(x+c):$ left c

### Reflection
$−f(x):$ reflect over x-axis

$f(−x):$ reflect over y-axis

### Scaling
$cf(x):$ vertical stretch/compression

$f(cx):$ horizontal compression/stretch (opposite effect)

### Combining Functions
Sum: $(f+g)(x)=f(x)+g(x)$

Difference: $(f−g)(x)=f(x)−g(x)$

Product: $(fg)(x)=f(x)g(x)$

Quotient: $(\frac{f}{g})(x)=\frac{f(x)}{g(x)}, g(x)\cancel{=}0$

### Composite Functions
$(f∘g)(x)=f(g(x))$

Perform inside function first, then outside.
Domain restrictions come from both functions.

### Common Graph Changes
$y=af(b(x−h))+k$

- a: vertical stretch/reflection
- b: horizontal stretch/reflection
- h: horizontal shift
- k: vertical shift

### Order of transformations:
Inside → horizontal → vertical → reflection/stretch (depending on form)

# Mathmatical Models
Math is often used to model real life. There are multiple ways models can reflect real life.
## Linear Models
When we say y is linear function of x, we were to draw it, it would be a straight line. Like a drag strip. This relationship can be written as 

$$
y = f(x) = mx + b
$$

where $m$ is the slope of this line and b is its y-intercept. 

## Polynomial
A function $P$ is called a polynomial if raising varibles to powers exists with in the equation.

$$P(x) = 2x^6 - x^4 + \frac{2}{5}x^3 + \sqrt2$$

This is a sixth degree polynomial as the highest exponent is a six. A first degree polynimal is simply a linear function. 

## Rational Functions
A rational function $f$ is a ration of two polynomials:

$$f(x) = \frac{P(x)}{Q(X)}$$

where both $P$ and $Q$ are polynomials. This function exists so long as $Q(x) \cancel{=} 0$
In the wild these look like

$$f(x) = \frac{2x^4-x^2+1}{x^2-4}$$

## Root functions
$$f(x) = \sqrt[n]{x}$$

## Reciprocal Functions
$$f(x) = \frac{1}{x^n}$$

## Exponential and Logarithmic Functions
$$f(x) = b^n$$

$$f(x) = \log_bx$$

## Trigonometric functions

$$f(x) = \sin x$$

$$f(x) = \cos x$$

$$f(x) = \tan x$$

# Cartesian Vectors

## Right-Handed Coordinate System

A right-handed coordinate system uses the $x$, $y$, and $z$ axes arranged so the positive directions follow the right-hand rule.

## Rectangular Components of a Vector

A vector can be resolved into components along the coordinate axes.

\(\vec{\mathbf{A}} = A_x\mathbf{i} + A_y\mathbf{j} + A_z\mathbf{k}\)

Where:

* $A_x$ = $x$ component
* $A_y$ = $y$ component
* $A_z$ = $z$ component
* $\mathbf{i},\mathbf{j},\mathbf{k}$ = unit vectors along the $x,y,z$ axes. 

You can just think of these as a "tag" indicating to which axial direction it belongs. 

## Cartesian Vector Representation

A vector can be represented using its magnitude and coordinate components.

\(\vec{\mathbf{A}} = A_x\mathbf{i} + A_y\mathbf{j} + A_z\mathbf{k}\)

For vector addition, add corresponding Cartesian components.

\(\vec{\mathbf{R}} = \vec{\mathbf{A}} + \vec{\mathbf{B}}\)

\(\vec{\mathbf{R}} = (A_x+B_x)\mathbf{i}+(A_y+B_y)\mathbf{j}+(A_z+B_z)\mathbf{k}\)

This is useful because vector addition becomes the addition of the individual $x$, $y$, and $z$ components.

## Magnitude of a Cartesian Vector

The magnitude of $\vec{\mathbf{A}}$ is found using the 3D Pythagorean theorem.

\(A=\lvert\vec{\mathbf{A}}\rvert=\sqrt{A_x^2+A_y^2+A_z^2}\)

## Coordinate Direction Angles

The coordinate direction angles $\alpha$, $\beta$, and $\gamma$ are the angles between $\vec{\mathbf{A}}$ and the positive $x$, $y$, and $z$ axes accordingly.

\(\cos\alpha=\frac{A_x}{A}\)

\(\cos\beta=\frac{A_y}{A}\)

\(\cos\gamma=\frac{A_z}{A}\)

Therefore,

\(A_x=A\cos\alpha\)

\(A_y=A\cos\beta\)

\(A_z=A\cos\gamma\)

The vector can then be written as

\(\vec{\mathbf{A}}=A(\cos\alpha\,\mathbf{i}+\cos\beta\,\mathbf{j}+\cos\gamma\,\mathbf{k})\)

This can also be broken down into a the unit vector: \(\vec{u}\)

\(\vec{u_A}=\frac{\vec{\mathbf{A}}}{A}\)

The direction angles satisfy

\(\cos^2\alpha+\cos^2\beta+\cos^2\gamma=1\)

## Horizontal and Vertical Angles

The direction of a vector can also be described using horizontal and vertical angles.

The projection of $\vec{\mathbf{A}}$ onto the $xy$ plane is

\(\vec{\mathbf{A}}_{xy}=A_x\mathbf{i}+A_y\mathbf{j}\)

Its magnitude is

\(A_{xy}=\sqrt{A_x^2+A_y^2}\)

The horizontal angle $\theta$ is measured in the $xy$ plane.

\(\tan\theta=\frac{A_y}{A_x}\)

The vertical angle $\phi$ describes the inclination of $\vec{\mathbf{A}}$ above or below the $xy$ plane.

\(\tan\phi=\frac{A_z}{A_{xy}}\)

The vector can therefore be described using its horizontal projection and vertical component.

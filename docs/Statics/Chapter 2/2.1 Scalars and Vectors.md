# Scalars and Vectors

A ***scalar*** is any positive or negative quantity without a direction, existing only as a magnitude. Examples are: mass, time, length, speed.

A ***vector***  is a quantity with both a magnitude and a velocity, examples are: velocity, acceleration, force. 

The primary differance can be thought of like this:

- Scalar = "How much?"
- Vector = "How much going where?"
- Scalar = 25MPH, Vector = 25MPH going North

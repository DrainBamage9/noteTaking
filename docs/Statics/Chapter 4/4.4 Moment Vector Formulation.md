# Moment Vector Formulation
The moment of a force about a point measures the force's tendency to rotate an object about that point. 
$$
\boxed{\mathbf{M_O}=\mathbf{r}\times{}\mathbf{F}}
$$
Where:

- $\mathbf{M_O}$ = Moment about point $O$
- $\mathbf{r}$ = Position vector from $O$ to any point along the **force's line of action**
- $\mathbf{F}$ = Force Vector

## Magnitude

The magnitude of the cross product is defined as $M_O=rF\sin{\theta}$, there the angle $\theta$ is measured between the *tails* fo $\mathbf{r}$ and $\mathbf{F}$. To define this angle $\mathbf{r}$ is a *sliding vector* such that $\theta$ can be properly evaluated. Since the moment arm can be defined such that $d = r\sin{\theta}$ we can evaluate:
$$
M_O = rF\sin{\theta}=F(r\sin{\theta})=Fd
$$

## Direction
Evaluated via the right hand rule, the curl of the fingers follows $\mathbf{r}$ toward $\mathbf{F}$, hence "r cross F". Then our thumb describes the direction of $\mathbf{$M_O}$.

## Principle of Transmissibilty
If we make the Force vector $\mathbf{F}$ infinitely long, no infinitely strong, we can draw $\mathbf{r}$ such that it intersects along any point of this line and it will always result in the same moment since the intersection angle $\theta$ changes dependant on where on the line this intersection happens. 

## Resultant Moments
If an object is acted on by multiple forces, the resultant moment about the point $O$ can be evaluated by vector addition of each moment of each force. Written as:
$$
\mathbf{M}_{RO}=\sum{}(\mathbf{r}\times{}\mathbf{F})
$$

# Three-Dimensional Force Systems

In the previous section it was stated that for an object to be in equilibrium that the sum of of the forces acting on it needs to be zero.

$$
\sum{}\mathbf{F}=0
$$

This condition can spread into three dimensions, creating a three-dimensional force system. And the sum rules stated in Coplanar Forces holds true here as well. $\sum{}F_x\mathbf{i}+\sum{}F_y\mathbf{j}+\sum{}F_z\mathbf{k}=0$ must be true for this three-dimensional force system to be in equilibrium.

$$
\boxed{
    \begin{aligned}
    \sum{}F_x=0\\
    \sum{}F_y=0\\
    \sum{}F_z=0
    \end{aligned}
}   
$$

These equations state that the sum of each component of **all** forces acting on an object along all of its axes needs to equal zero.

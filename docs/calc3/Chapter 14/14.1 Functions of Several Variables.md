### Functions of Several Variables

Some functions are multivariate, like temperature on a surface. These function are usually written as:

$$f(x,y) \ or \ f(x,y,z)$$

#### Example

Given the multivariate function:$f(x,y) = x^2 + y^2$

We can determine this is a parabolic bowl shaped function given:


$$f(x,0)=x^2$$

$$f(0,y)=y^2$$

Both are upwards opening parabolas. Surface is a 3D bowl centered at origin.
